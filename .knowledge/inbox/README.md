# Knowledge Inbox

Inbox contains unapproved candidate knowledge.

- Every entry uses `kind: candidate` and `status: draft`.
- Entries include provenance, evidence, impact, conflicts, and a proposed destination.
- Inbox is excluded from default Agent retrieval.
- Promotion requires repository verification, review, and explicit TASK scope.
- Security, authorization, privacy, public-contract, and architecture-policy candidates require human confirmation.
