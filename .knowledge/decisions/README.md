# Architecture Decisions

Architecture decisions use `adr-YYYYMMDD-topic.md` and the ADR template.

- An Agent may create `proposed` ADRs within TASK scope.
- `accepted`, `rejected`, and `superseded` decisions require recorded human review.
- Accepted ADRs are historical records and are not rewritten to reverse a decision.
- A replacement ADR uses `supersedes` and the old ADR records `superseded_by`.
- Only accepted ADRs participate in default implementation navigation.
