# Legacy Reference - AI Guides

This directory contains historical guide material, prior delivery reports, and older phase contracts.

It is no longer a direct implementation input. A folder that contains `constitution.md`, `spec.md`, `plan.md`, and `tasks.md` is treated as a legacy phase contract until it is revalidated and migrated into a current `.spec/<feature-name>/` package.

Freeze does not mean cancellation. Pending or incomplete phase work should be migrated on demand, with current-code analysis and user confirmation, before any implementation starts.

Delivery reports and acceptance reviews in this directory are historical evidence. Do not delete them, rewrite their conclusions, or mark old phase tasks as active/done/cancelled during migration inventory work.

Canonical execution sources:

- `AGENTS.md`
- `.agents/skills/spec-harness/SKILL.md`
- `.agents/skills/harness-pipeline/SKILL.md` when explicitly requested
- `.spec/<feature-name>/`
