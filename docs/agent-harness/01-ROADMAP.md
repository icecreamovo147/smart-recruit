## M0：Harness 建立

- **阶段目标**：建立工程约束体系，为后续开发建立轨道
- **包含缺陷**：无（基础设施）
- **前置条件**：缺陷调研报告已完成
- **输出物**：`docs/agent-harness/` 全部文档 + 第一批任务文件
- **验收标准**：
  - 所有 Harness 文档存在且内容完整
  - 第一批任务文件内容合格
  - 文档间无明显矛盾
- **不属于本阶段的内容**：任何代码实现

---

## M1：Agent 可见性与可观测性

- **阶段目标**：用户能看见 Agent 的执行过程——当前使用的模型、调用了哪个工具、入参和结果是什么、有没有出错
- **包含缺陷**：
  - 缺陷 6：Agent 执行轨迹后端已落库但前端零展示
  - 缺陷 13：当前 Agent / 模型 / 数据源状态不明确
  - 缺陷 15：错误重试展示不统一
  - 缺陷 10（部分）：对话内结果展示弱
- **前置条件**：M0 完成
- **涉及模块**：`hr-frontend/src/views/hr/AIChatView.vue`、`logic-grpc-service/service/ai_service.go`、`logic-grpc-service/repository/tool_trace_repo.go`
- **输出物**：
  - P0-001 任务：HR 端失败重试按钮
  - P0-002 任务：聊天页状态栏（模型/数据源标识）
  - P0-003 任务：Agent 执行轨迹查询接口
  - P0-004 任务：Agent 执行轨迹前端面板
  - P1-011 任务：脱敏中间件与高风险工具二次确认（部分：Trace 脱敏先落地）
- **验收标准**：
  - 聊天页显示当前模型、数据来源标识
  - 工具调用过程在前端时间线可视化（工具名/入参/结果/耗时）
  - HR 端失败消息可重试
  - 非侵入式，不破坏已有对话功能
- **不属于本阶段的内容**：
  - 模型切换功能（M2）
  - 成本统计（M3）
  - 调试面板（M3）

---

## M2：模型与 Prompt 配置化

- **阶段目标**：管理员可通过页面配置 LLM Provider/模型/参数/Prompt，无需修改代码或重启服务
- **包含缺陷**：
  - 缺陷 1：模型与 Provider 不可视化配置
  - 缺陷 3：System Prompt 硬编码
- **前置条件**：M1 完成（聊天页状态栏先就位，模型配置页才有展示载体）
- **涉及模块**：`logic-grpc-service/config/`、`ai/`、`hr-frontend/src/` 新增模型配置页
- **输出物**：
  - P0-005：模型配置中心-后端（含 API Key 加密存储）
  - P0-006：模型配置中心-前端
  - P1-001：Prompt 管理-后端
  - P1-002：Prompt 管理-前端
  - P1-010：输入区增强（工具/知识库/数据源开关 + 会话绑定）
  - P1-011：脱敏中间件与高风险工具二次确认（部分：API Key 相关 + 通用脱敏函数）
- **验收标准**：
  - 新增 Provider/Model 配置页（CRUD + 连接测试）
  - 聊天页顶部可切换模型（按会话）
  - Prompt 模板页支持 CRUD + 版本 + 变量
  - 配置变更即时生效（无需重启）
- **不属于本阶段的内容**：
  - Agent 编排（M6）
  - MCP 工具管理（M4）
  - 非 OpenAI 兼容的原生 Provider 接入（M4 阶段评估）

---

## M3：成本统计与调试能力

- **阶段目标**：能按维度查看 AI 使用成本，有在线调试面板
- **包含缺陷**：
  - 缺陷 7：无独立 Token / 成本统计与调试面板
  - 缺陷 11（部分）：输入区增强（M2 已做模型选择）
- **前置条件**：M2 完成（Provider/模型管理就绪后才能精确统计）
- **涉及模块**：`logic-grpc-service/` `ThirdPartyUsageLog` 表查询增强，`hr-frontend/src/views/hr/admin/` 增强，新增 Playground 页
- **输出物**：
  - P1-003：AI 成本统计增强
  - P1-008：调试面板-后端
  - P1-009：调试面板-前端
  - P1-011：脱敏中间件与高风险工具二次确认（部分：高风险工具确认先落地）
- **验收标准**：
  - 成本统计页：用户/模型/会话维度聚合 + 趋势图
  - 调试面板：在线对话 + 原始 messages/请求参数/响应/Trace 查看
- **不属于本阶段的内容**：
  - 预算告警
  - 真实 usage token 接入（当前仅估算）

---

## M4：MCP 工具与工具权限

- **阶段目标**：工具不再硬编码 Go，可通过 MCP 动态接入外部工具，具备工具级权限控制与调用安全
- **包含缺陷**：
  - 缺陷 4：无 MCP 工具能力
  - 缺陷 12（部分）：高风险工具二次确认 + 工具权限控制
- **前置条件**：M2 完成（需要模型配置支持 function calling）
- **涉及模块**：新型 MCP 管理服务、新增前端工具中心页面
- **输出物**：
  - P1-006：MCP Server 管理-后端
  - P1-007：MCP Server 管理-前端
  - P1-011：脱敏中间件与高风险工具二次确认（部分：工具二级权限确认）
  - 聊天页工具调用可视化增强（M1 基础上升级，P0-004 增强）
- **验收标准**：
  - 支持添加/配置/连接测试 MCP Server
  - 工具列表与 Schema 可查看
  - 工具可启用/禁用
  - 按角色控制工具可用性
  - 高风险工具二次确认
- **不属于本阶段的内容**：
  - Skills（M6）
  - 通用 Tool Calling 协议（非 MCP 的外部工具）

---

## M5：数据源、字段语义与知识库 / RAG

- **阶段目标**：Agent 能基于企业私有知识回答，数据查询不再硬编码
- **包含缺陷**：
  - 缺陷 8：无数据源管理 / 字段语义
  - 缺陷 9：无知识库 / RAG
  - 缺陷 10（部分）：引用来源展示
- **前置条件**：M4 完成（工具可扩展后，知识检索可作为新工具接入）
- **涉及模块**：新增数据源管理服务、向量库（选型需 ADR）、RAG pipeline
- **输出物**：
  - P1-012：数据源管理-后端
  - P1-013：数据源管理-前端
  - P1-014：知识库/RAG-后端
  - P1-015：知识库/RAG-前端（含聊天页引用来源展示）
- **验收标准**：
  - 数据源可配置连接、查看 Schema、标注字段语义
  - 知识库可上传文档、切片、索引
  - 对话中可展示引用来源
  - RAG 检索可开关
- **不属于本阶段的内容**：
  - 多模态检索
  - GraphRAG

---

## M6：Skills 与 Agent 编排

- **阶段目标**：支持多 Agent 协作、工作流编排、Skills 管理
- **包含缺陷**：
  - 缺陷 2：Agent 配置全部硬编码
  - 缺陷 5：无 Skills 能力
- **前置条件**：M2+M4 完成（需要模型和工具管理基础设施）
- **涉及模块**：新增 Agent 编排服务、Skills 管理服务
- **输出物**：
  - P1-004：Agent 配置管理-后端
  - P1-005：Agent 配置管理-前端
  - P2-001：Skills 管理（前后端合并）
- **验收标准**：
  - Agent 可通过页面创建/编辑/删除
  - Agent 可绑定模型/工具/Prompt/数据源
  - Skills 可安装/启用/禁用
  - 支持多 Agent 场景
- **不属于本阶段的内容**：
  - 复杂 DAG 工作流编排

---

## M7：体验增强与长期优化

- **阶段目标**：打磨聊天体验、面试官 AI 助手、结构化结果展示
- **包含缺陷**：
  - 缺陷 10（剩余）：SQL 展示、图表、导出
  - 缺陷 14：面试官端无 AI 能力
  - 其他 P3 项
- **前置条件**：M5/M6 完成
- **输出物**：
  - P2-002：对话结构化结果展示（SQL/图表/导出）
  - P3-001：面试官端 AI 助手
- **验收标准**：按具体任务定义

## 阶段依赖图

```
M0 (Harness)
 |
M1 (可见性/可观测性) ← 优先，复用已有数据
 |
M2 (模型/Prompt配置) ← 基础设施
 |
├─ M3 (成本/调试) ← 依赖 M2 数据
 |
M4 (MCP/工具权限) ← 依赖 M2
 |
M5 (数据源/RAG) ← 依赖 M4
 |
M6 (Skills/编排) ← 依赖 M2+M4
 |
M7 (体验优化) ← 长期
```
