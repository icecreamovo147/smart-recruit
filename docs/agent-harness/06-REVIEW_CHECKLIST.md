# 06-REVIEW_CHECKLIST — 验收核查清单

> 版本：v1.0
> 创建日期：2026-06-26
> 用途：供 Reviewer（人或 Agent）在任务完成后逐项核查

---

## 核查清单

| # | 检查项 | 检查方法 | 通过条件 |
|---|--------|----------|----------|
| 1 | **严格遵守任务范围** | 对比任务文件中「允许修改的文件」与实际变更 | 无超范围修改 |
| 2 | **未修改禁止修改文件** | 对比任务文件中「禁止修改的文件」与实际变更 | `git diff --name-only` 不在禁止列表 |
| 3 | **未引入不必要依赖** | 检查 go.mod / package.json diff | 新依赖在 ADR 中说明且必要 |
| 4 | **未破坏现有功能** | 运行全量测试 + 检查已有路由/gRPC/页面 | 已有测试全部通过 |
| 5 | **权限校验完整** | 检查新接口/路由是否有 perm 声明 | 新接口有 perm 且合理 |
| 6 | **migration 正确** | 检查新 migration 版本号是否递增、是否有 down 文件 | 版本号连续、可回滚 |
| 7 | **脱敏到位** | 检查 Trace/日志/响应中的敏感字段 | 无明文手机号/身份证/API Key |
| 8 | **有测试** | 检查是否有新增测试文件 | 关键逻辑有测试 |
| 9 | **无 TODO/FIXME** | grep 搜索 `TODO\|FIXME\|HACK` | 零命中 |
| 10 | **无调试代码** | grep 搜索 `console\.log\|fmt\.Println\|dump\|var_dump` | 零残留调试代码 |
| 11 | **无硬编码密钥** | grep 搜索 `sk-\|api_key.*=.*\".*\"\|API_KEY.*=.*\".*\"` | 零命中（配置文件排除） |
| 12 | **无大范围重构** | 检查 diff 规模与任务范围是否匹配 | 无超出任务需要的重构 |
| 13 | **构建通过** | 运行构建命令 | `vite build` / `go build` 通过 |
| 14 | **类型检查通过** | 运行类型检查 | `vue-tsc --noEmit` / `go vet` 通过 |
| 15 | **任务状态已更新** | 检查任务文件末尾 | 有完成日期和验证结果 |
| 16 | **TRACEABILITY_MATRIX 已更新** | 检查对应缺陷状态 | 状态已从「待开发」变更 |
| 17 | **文档已更新** | 检查 ADR / README / 注释 | 按需要更新 |
| 18 | **ADK / Legacy 双运行时正常** | 检查 `ai/adk_agent.go` 和 `ai/eino_client.go` 未被破坏 | 业务运行时不报错 |
| 19 | **API Key 不泄露** | 检查 HTTP 响应体 / SSE 输出 / 日志 | 密钥不暴露 |
| 20 | **敏感日志检查** | 检查日志输出是否含简历内容 / 完整手机号 | 日志不含敏感信息 |
