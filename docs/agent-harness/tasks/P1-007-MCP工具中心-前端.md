# 任务编号：P1-007

## 1. 任务目标

在 HR 管理端新增「工具中心」页面，对接 P1-006 创建的 MCP 管理接口，支持可视化管理 MCP Server、查看工具列表与 Schema、查看工具调用日志。

## 2. 对应缺陷

- **缺陷 4**：无 MCP 工具能力（前端侧）

## 3. 前置条件

- P1-006 完成（后端接口可用）

## 4. 允许修改的文件

- `hr-frontend/src/router/index.ts`
- `hr-frontend/src/App.vue`
- `hr-frontend/src/views/hr/admin/`（新增 McpManageView.vue）
- `hr-frontend/src/api/`（新增 mcp.ts）
- `hr-frontend/src/types/`（新增 mcp.ts 类型）

## 5. 禁止修改的文件

- `logic-grpc-service/` 下所有文件
- `web-gin-service/` 下所有文件
- 已有业务页面

## 6. 实现步骤

### 6.1 路由与菜单

- 新增路由 `/hr/admin/mcp-tools`，`meta.perm: PERM.SYSTEM_CONFIG_MANAGE`
- 在侧边栏菜单新增「工具中心」菜单项

### 6.2 页面设计

1. **MCP Server 管理（主视图）**：
   - `el-table` 展示 Server 名称/传输类型/状态/工具数量/操作
   - 新增/编辑弹窗：
     - 名称、传输类型（select: stdio/sse/http）
     - 命令/URL（按传输类型动态切换表单项）
     - 参数配置、环境变量编辑
     - 超时设置
     - 连接测试按钮
   - 操作：启用/禁用、连接测试、查看工具列表、删除

2. **工具列表（子视图）**：
   - 选择某个 MCP Server 后展示其工具列表
   - 表格：工具名称、描述、输入 Schema（JSON 折叠展示）
   - 操作：查看 Schema 详情

3. **工具调用日志（子视图）**：
   - 按 MCP Server / 工具名 / 时间筛选
   - 表格：时间、工具名、入参摘要、结果摘要、耗时、状态
   - 日志详情弹窗（完整入参/结果，脱敏后展示）
