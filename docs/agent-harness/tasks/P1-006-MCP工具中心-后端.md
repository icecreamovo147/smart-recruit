# 任务编号：P1-006

## 1. 任务目标

引入 MCP（Model Context Protocol）SDK，新增 MCP Server 管理和工具调用能力。后端支持注册/管理 MCP Server、查看工具列表与 Schema、执行工具调用并记录日志。

> 注意：本任务是平台架构级变更，执行前必须创建 ADR 说明 MCP SDK 选型、安全沙箱方案、与现有工具体系的共存策略。

## 2. 对应缺陷

- **缺陷 4**：无 MCP 工具能力（后端侧）

## 3. 前置条件

- P0-005 完成（Provider/Model 管理就绪，因为 MCP 工具调用需要 LLM function calling）
- 必须先创建 ADR：MCP SDK 选型 + 安全沙箱方案

## 4. 允许修改的文件

- `logic-grpc-service/go.mod`（新增 MCP SDK 依赖）
- `logic-grpc-service/proto/recruitment.proto`
- `logic-grpc-service/recruitment/pb/`
- `logic-grpc-service/model/model.go`
- `logic-grpc-service/repository/`（新增 mcp_repo.go）
- `logic-grpc-service/service/`（新增 mcp_service.go）
- `logic-grpc-service/migrations/`（新增 migration）
- `logic-grpc-service/main.go`
- `logic-grpc-service/config/config.go`（新增 MCP 相关配置）
- `web-gin-service/proto/recruitment.proto`（同步）
- `web-gin-service/recruitment/pb/`（同步）
- `web-gin-service/router/router.go`
- `web-gin-service/handler/`（新增 handler）

## 5. 禁止修改的文件

- `ai/adk_agent.go`（不改变 Agent 核心创建，MCP 工具作为附加工具注入）
- `ai/hr_adk_tools.go`、`ai/candidate_adk_tools.go`（已有硬编码工具保留）
- 已有业务服务

## 6. 实现步骤

### 6.1 数据库

新增表 `mcp_servers`：
- `id`、`name`、`transport`（stdio/sse/http）、`command_or_url`、`args`（JSON）、`env_vars`（JSON）、`timeout_seconds`、`is_enabled`、`created_at`、`updated_at`

新增表 `mcp_tool_logs`：
- `id`、`server_id`、`tool_name`、`args_json`（脱敏）、`result_content`（脱敏/截断）、`duration_ms`、`error_msg`、`called_by_hr_id`、`session_id`、`created_at`

### 6.2 后端

1. 引入 MCP Go SDK（如 `mark3labs/mcp-go`）
2. 新增 proto rpc：
   - `ListMCPServers` / `CreateMCPServer` / `UpdateMCPServer` / `DeleteMCPServer` / `TestMCPConnection`
   - `ListMCPTools`（列出某 Server 的工具列表与 Schema）
   - `CallMCPTool`（执行工具调用，内部使用）
3. 新增 `MCPService`
4. MCP Server 连接管理：启动/停止/健康检查
5. 工具调用：传入 tool_name + args，返回 result + error
6. 工具调用日志：记录到 `mcp_tool_logs` 表
7. 将 MCP 工具注入 ADK Agent 工具列表（与已有硬编码工具合并为统一的工具集）

## 7. 数据库变更

- 新增表：`mcp_servers`、`mcp_tool_logs`
- Migration：`NNNNNN_add_mcp_servers.sql` + down

## 8. 接口变更

- 新增 gRPC service：`MCPService`（或追加到已有服务）
- method：`ListMCPServers` / `CreateMCPServer` / `UpdateMCPServer` / `DeleteMCPServer` / `TestMCPConnection` / `ListMCPTools` / `CallMCPTool`

## 9. 前端变更

不涉及（P1-007 任务）

## 10. 权限与安全要求

- MCP Server 管理接口需 `SYSTEM_CONFIG_MANAGE` 权限
- 外部 MCP Server 默认禁用（`is_enabled=false`），需手动启用
- MCP 工具调用需超时控制（默认 30s）
- `CallMCPTool` 需记录完整审计日志
- 入参/结果需脱敏后记录
