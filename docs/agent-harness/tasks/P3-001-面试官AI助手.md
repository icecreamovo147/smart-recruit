# 任务编号：P3-001

## 1. 任务目标

为面试官端（`interviewer-frontend`）新增 AI 助手能力：在面试详情页提供面试评价辅助、结构化面试问题生成、候选人简历要点提炼。

> 注意：本任务是长期优化项（P3），前期需要评估面试官端 AI 需求优先级。如需求不急迫可推迟。

## 2. 对应缺陷

- **缺陷 14**：面试官端完全无 AI 能力

## 3. 前置条件

- P1-004 完成（Agent 配置管理就绪，需新增 interviewer_agent 类型）
- P1-005 完成（Agent 管理前端就绪）
- 面试官端需增加 markdown-it 和 DOMPurify 依赖（当前缺失）

## 4. 允许修改的文件

- `interviewer-frontend/package.json`（新增 markdown-it、dompurify 依赖）
- `interviewer-frontend/src/views/`（新增 AI 助手组件或在 InterviewDetailView 中嵌入）
- `interviewer-frontend/src/api/`（新增 ai.ts）
- `interviewer-frontend/src/types/`（新增 ai.ts）
- `interviewer-frontend/src/router/index.ts`
- `logic-grpc-service/proto/recruitment.proto`（新增面试官 AI 相关 rpc，或复用已有 AIService）
- `logic-grpc-service/service/`（新增 interviewer_ai_service.go）
- `web-gin-service/` 对应路由与 handler

## 5. 禁止修改的文件

- `ai/adk_agent.go`（新增 interviewer agent 配置，不改变核心逻辑）
- `hr-frontend/` 和 `user-frontend/` 下所有文件
- 已有面试服务逻辑

## 6. 实现步骤

### 6.1 后端

1. 新增 Agent 类型：`interviewer_assistant`
2. 面试官 AI 工具：
   - `get_interview_info`：获取当前面试信息（候选人/岗位/面试轮次）
   - `get_candidate_resume_summary`：获取候选人简历要点（脱敏后）
   - `generate_interview_questions`：基于岗位要求生成结构化面试问题
3. SSE 流式对话接口（复用已有 ChatStream 模式）

### 6.2 前端

1. 在面试详情页（`InterviewDetailView.vue`）新增「AI 助手」浮动按钮
2. 点击后展开侧边栏 AI 对话面板
3. AI 功能入口：
   - 「生成面试问题」快捷按钮
   - 「候选人要点提炼」快捷按钮
   - 「面试评价辅助」快捷按钮
   - 自由对话输入框
4. 添加 markdown-it + DOMPurify 用于回复渲染
