## 6. 实现步骤

1. 阅读 `CandidateAIAssistant.vue:351-354` 的重试实现逻辑作为参考
2. 在 `AIChatView.vue` 的失败消息 bubble 区域增加重试按钮
3. 重试逻辑：使用失败消息的上一条用户消息内容重新调用 `submit()` 或等效方法
4. 重试后移除当前失败消息（或标记为已重试）
5. 按钮样式：Element Plus `el-button` `type="warning"` `size="small"` + "重新发送"文字
