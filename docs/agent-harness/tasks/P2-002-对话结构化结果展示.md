# 任务编号：P2-002

## 1. 任务目标

增强 HR 端聊天消息的结构化结果展示能力：支持 SQL 代码块渲染、图表渲染（ECharts）、引用来源展示、结果数据导出（CSV/Excel）。

## 2. 对应缺陷

- **缺陷 10**：对话内结果展示弱，缺 SQL / 图表 / 引用 / 导出

## 3. 前置条件

- M5 阶段完成后（知识库就绪才有引用来源；数据源管理就绪才有 SQL 展示场景）
- P0-004 完成（轨迹面板就绪）

## 4. 允许修改的文件

- `hr-frontend/src/views/hr/AIChatView.vue`
- `hr-frontend/src/components/`（新增结构化消息渲染组件）

## 5. 禁止修改的文件

- `logic-grpc-service/` 下所有文件
- `web-gin-service/` 下所有文件
- 前端 API 层和类型层

## 6. 实现步骤

### 6.1 SQL 代码块展示

1. 扩展 markdown-it 渲染规则：检测 `sql` 代码块
2. SQL 代码块增加特殊样式（代码高亮 + 表格图标 +「查看结果」按钮）
3. 「查看结果」按钮触发数据查询（预留接口）

### 6.2 图表渲染

1. 当 AI 回复中包含图表数据时（如 `chart` action 或特殊标记），渲染为 ECharts 图表
2. 支持柱状图/折线图/饼图（与已有 Analytics 页面风格一致）
3. 图表数据格式：LLM 输出 JSON 结构 `{type, data, options}`

### 6.3 引用来源展示

1. 依赖 P1-015 聊天页引用展示（如已完成则增强）
2. 展示格式：文档名称 + 相关片段摘要 + 相似度

### 6.4 数据导出

1. 在 AI 回复中添加「导出」按钮（当回复含表格数据时）
2. 导出格式：CSV / Excel
3. 实现：前端导出，不经过后端
