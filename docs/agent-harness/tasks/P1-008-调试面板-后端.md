# 任务编号：P1-008

## 1. 任务目标

新增调试面板/Playground 后端能力：支持内部 gRPC 流式调用用于在线调试 Agent，透传原始 messages、模型请求参数、模型响应、工具调用 Trace。

## 6. 实现步骤

1. 新增 proto rpc：
   - `DebugChatStream`：Server Stream，类似 `ChatStream`，但额外返回原始 messages 和模型请求参数
2. 实现 `DebugService`
3. 透传信息：
   - 请求前：返回 `event_type=debug_request`，payload 含完整 messages 数组和模型参数（不含 API Key）
   - 工具调用：返回 `event_type=tool_call`，含 tool_name + args
   - 工具结果：返回 `event_type=tool_result`，含 result_content
   - 最终回复：正常 streaming output
   - 完成后：返回 `event_type=debug_summary`，含 token 估算 + 总耗时 + 各工具耗时
4. 复用已有 `AIToolTrace` 表记录调试会话的工具调用
