# 任务编号：P1-015

## 1. 任务目标

在 HR 管理端新增「知识库」页面，对接 P1-014 的知识库管理接口。支持创建知识库、上传文档、查看文档切片状态、测试检索效果。聊天页增加引用来源展示。

## 2. 对应缺陷

- **缺陷 9**：无知识库 / RAG（前端侧）
- **缺陷 10**（部分）：引用来源展示

## 3. 前置条件

- P1-014 完成（后端接口可用）
- P1-010 完成（输入区知识库开关就绪）

## 4. 允许修改的文件

- `hr-frontend/src/router/index.ts`
- `hr-frontend/src/App.vue`
- `hr-frontend/src/views/hr/admin/`（新增 KnowledgeBaseView.vue）
- `hr-frontend/src/api/`（新增 kb.ts）
- `hr-frontend/src/types/`（新增 kb.ts 类型）
- `hr-frontend/src/views/hr/AIChatView.vue`（新增引用来源展示）

## 5. 禁止修改的文件

- `logic-grpc-service/` 下所有文件
- `web-gin-service/` 下所有文件
- 已有业务页面（AIChatView 新增功能不破坏已有）

## 6. 实现步骤

### 6.1 路由与菜单

- 新增路由 `/hr/admin/knowledge-base`，`meta.perm: PERM.SYSTEM_CONFIG_MANAGE`
- 在侧边栏菜单新增「知识库」菜单项

### 6.2 知识库管理页面

1. **知识库列表**：`el-table` 展示名称/描述/文档数/状态/操作
2. **文档管理**：
   - 文档列表（表格 + 上传按钮 + 搜索）
   - 上传文档：`el-upload` + drag-and-drop + 文件类型/大小校验
   - 文档状态展示：uploading → chunking → embedding → ready → error
   - 切片查看：点击文档查看切片列表（切片内容 + 索引状态）
3. **检索测试**：
   - 搜索输入框 + 检索按钮
   - 结果展示：相关片段 + 文档来源 + 相似度分数

### 6.3 聊天页引用来源展示

1. 在 `AIChatView.vue` 的 AI 回复气泡下方新增「引用来源」行
2. SS 监听 RAG 检索结果事件
3. 展示格式：文档图标 + 文档标题 + 相关度分数，可点击查看片段详情
4. 使用 `el-tag` 或折叠面板展示
