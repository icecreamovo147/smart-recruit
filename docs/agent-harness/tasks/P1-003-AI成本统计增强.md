### 聚合查询 SQL 确认

```sql
-- 按模型统计
SELECT COALESCE(model, 'unknown') AS name,
       COALESCE(SUM(estimated_tokens), 0) AS total_tokens,
       COUNT(*) AS call_count,
       COALESCE(AVG(cost_ms), 0) AS avg_cost_ms,
       COALESCE(SUM(estimated_tokens) * 0.002 / 1000, 0) AS estimated_cost
FROM third_party_usage_logs
WHERE created_at BETWEEN ? AND ?
GROUP BY model
ORDER BY total_tokens DESC;

-- 按用户统计（Top 10）
SELECT CAST(user_id AS CHAR) AS name, ...  -- same aggregations
FROM third_party_usage_logs
WHERE created_at BETWEEN ? AND ?
GROUP BY user_id
ORDER BY total_tokens DESC
LIMIT 10;

-- 按天趋势
SELECT DATE(created_at) AS date,
       COALESCE(SUM(estimated_tokens), 0) AS total_tokens,
       COUNT(*) AS call_count,
       COALESCE(AVG(cost_ms), 0) AS avg_cost_ms,
       COALESCE(SUM(estimated_tokens) * 0.002 / 1000, 0) AS estimated_cost
FROM third_party_usage_logs
WHERE created_at BETWEEN ? AND ?
GROUP BY date
ORDER BY date ASC;
```

### 已知限制

- 花费估算基于简单公式 `estimated_tokens * 0.002 / 1000`，未区分不同模型定价
- ECharts 饼图仅在 model 维度展示（user/session 维度以表格展示）
