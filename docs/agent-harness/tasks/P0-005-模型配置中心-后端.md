# 任务编号：P0-005

## 1. 任务目标

新增 LLM Provider 和 Model 的管理后端能力：包括 gRPC 服务方法、数据库 migration（Provider 配置表 + Model 配置表）、配置 CRUD 逻辑、LLM 客户端从配置读取 Provider/Model 参数。本任务是 M2 阶段的后端基础。

## 2. 对应缺陷

- **缺陷 1**：模型与 Provider 不可视化配置（后端侧）
- **缺陷 12**：API Key 明文存储（Key 加密存储在本任务实现）

- 无

## 6. 实现步骤

### 6.1 数据库 Design（需先写 ADR）

1. 新增表 `llm_providers`：
   - `id`, `name`, `base_url`, `api_key_encrypted`（AES-256-GCM 加密存储）, `provider_type`（openai_compatible/anthropic/deepseek/ollama）, `extra_headers`（JSON）, `is_enabled`, `created_at`, `updated_at`
2. 新增表 `llm_models`：
   - `id`, `provider_id`（FK）, `model_name`, `display_name`, `temperature`（float64）, `top_p`, `max_tokens`, `max_concurrency`, `timeout_seconds`, `is_enabled`, `is_default`, `created_at`, `updated_at`
3. 新增 migration 文件（版本号在已有最大版本号 +1）

### 6.2 后端实现

1. 新增 proto message 和 rpc：
   - `ListProviders` / `CreateProvider` / `UpdateProvider` / `DeleteProvider` / `TestProviderConnection`
   - `ListModels` / `CreateModel` / `UpdateModel` / `DeleteModel`
2. 新增 `LlmConfigService` gRPC 服务实现
3. API Key 加密：使用 `crypto/aes` + `crypto/cipher` AES-256-GCM，密钥从环境变量 `ENCRYPTION_KEY` 读取
4. API Key 脱敏：返回前端时只显示前 4 位 + 后 4 位
5. 连接测试：使用配置的 base_url + api_key 调用 `/v1/models` 端点（OpenAI 兼容接口），10s 超时
6. 修改 `ai/eino_client.go` 的 LLM 客户端创建：优先从配置表读取，回退到环境变量配置

### 6.3 写在 ADR 中的决策

- 加密算法选型：AES-256-GCM
- `ENCRYPTION_KEY` 的来源与管理
- Provider 表的 `extra_headers` 用途（如 Anthropic API 需要 `x-api-key` header 替代 `Authorization`）
- 与已有 `AI_BASE_URL` / `AI_API_KEY` / `AI_MODEL` 环境变量的兼容策略

## 7. 数据库变更

- 新增表：`llm_providers`、`llm_models`
- Migration 文件：`NNNNNN_add_llm_providers.sql` + 对应 down 文件

## 8. 接口变更

- 新增 gRPC service：`LlmConfigService`
- 新增 method：`ListProviders` / `CreateProvider` / `UpdateProvider` / `DeleteProvider` / `TestProviderConnection` / `ListModels` / `CreateModel` / `UpdateModel` / `DeleteModel`

## 9. 前端变更

不涉及（P0-006 任务处理）

## 10. 权限与安全要求

- 所有 Provider/Model 管理接口需要 `SYSTEM_CONFIG_MANAGE` 权限（该常量已定义）
- `api_key_encrypted` 字段永远不返回给前端
- API Key 返回前端时脱敏为 `sk-xx****xxxx`
- `extra_headers` 中可能包含额外密钥，需在返回前端时脱敏
- 日志中不得出现 API Key 明文
