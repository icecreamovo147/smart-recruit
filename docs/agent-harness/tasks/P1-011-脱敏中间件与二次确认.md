# 任务编号：P1-011

## 1. 任务目标

新增统一敏感字段脱敏中间件和高风险工具调用二次确认机制。目标：简历数据/手机号/身份证等敏感字段在 Trace、日志、API 响应中自动脱敏；高风险工具调用需前端二次确认。

## 2. 对应缺陷

- **缺陷 12**：API Key 明文/无脱敏/无二次确认（脱敏 + 二次确认部分）
- 注：API Key 加密存储已在 P0-005 覆盖

## 3. 前置条件

- P0-005 完成（API Key 加密就绪，本任务补充通用脱敏）
- P0-003 完成（Trace 脱敏就绪，本任务提供通用脱敏函数）

## 4. 允许修改的文件

- `logic-grpc-service/pkg/`（新增 desensitize.go 脱敏工具包）
- `logic-grpc-service/service/ai_service.go`（`recordToolTrace` 增加脱敏调用）
- `logic-grpc-service/service/agent_context.go`（如 Agent 上下文含敏感字段）
- `logic-grpc-service/repository/tool_trace_repo.go`（入参脱敏）
- `logic-grpc-service/middleware/`（如需要，新增脱敏中间件）
- `hr-frontend/src/views/hr/AIChatView.vue`（高风险操作二次确认弹窗）

## 5. 禁止修改的文件

- `ai/adk_agent.go`、`ai/eino_client.go`
- 已有业务服务核心逻辑

## 6. 实现步骤

### 6.1 脱敏工具包

1. 新增 `pkg/desensitize/desensitize.go`：
   - `MaskPhone(phone string) string` → `138****1234`
   - `MaskIDCard(id string) string` → `110101****1234`
   - `MaskEmail(email string) string` → `a***@example.com`
   - `MaskJSON(jsonStr string, sensitiveFields []string) string` → 递归脱敏 JSON 中指定字段
   - `TruncateResume(text string, maxLen int) string` → 简历正文截断
2. 在 `recordToolTrace` 调用脱敏函数处理入参和结果
3. 在日志输出层增加脱敏钩子

### 6.2 高风险工具二次确认

1. 定义高风险工具清单（如：发送面试邀约邮件、状态变更等写操作）
2. 在 Agent 中间件 `adk_middleware.go` 中检测高风险工具调用
3. SSE 推送 `event_type=tool_confirm_required`，前端展示确认弹窗
4. 用户确认后继续执行；拒绝后取消工具调用并返回友好提示
5. 确认/拒绝记录到审计日志

### 6.3 前端二次确认 UI

1. 在 `AIChatView.vue` 监听 SSE `tool_confirm_required` 事件
2. 弹出 `el-message-box` 确认弹窗（工具名 + 操作说明 + 确认/取消按钮）
3. 通过 SSE 回传确认/取消结果
