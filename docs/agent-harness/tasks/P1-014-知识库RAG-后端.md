## 6. 实现步骤

### 6.1 数据库 + 向量库

向量数据库选型需要 ADR。候选方案：
- **轻量方案**：MySQL + pgvector 兼容层 或 内嵌 Chroma
- **生产方案**：Milvus / Qdrant / Weaviate

新增关系表 `knowledge_bases`：
- `id`、`name`、`description`、`embedding_model`、`is_enabled`、`created_at`、`updated_at`

新增关系表 `knowledge_documents`：
- `id`、`kb_id`、`title`、`file_path`、`file_type`、`file_size`、`chunk_count`、`status`（uploading/chunking/embedding/ready/error）、`created_at`

### 6.2 后端实现

1. 新增 proto rpc：
   - 知识库管理：`ListKnowledgeBases` / `CreateKnowledgeBase` / `UpdateKnowledgeBase` / `DeleteKnowledgeBase`
   - 文档管理：`UploadDocument` / `ListDocuments` / `DeleteDocument` / `GetDocumentChunks`
   - 检索接口：`SearchKnowledge`（传入 query → 返回相关文档片段 + 相似度分）
2. 文档处理 pipeline：
   - 上传 → 文件类型校验 → 文本提取（PDF/DOCX/TXT/MD）
   - 切片：按段落/semantic splitter 切分，chunk_size=500, chunk_overlap=50
   - Embedding：调用 Embedding API 生成向量
   - 索引：写入向量数据库
3. 检索 pipeline：
   - Query → Embedding → 向量检索（TopK=5~10）→ Rerank（可选）→ 返回结果
4. RAG 作为 Agent 工具接入：新增 `search_knowledge_base` 工具，注入到 Agent 工具列表
