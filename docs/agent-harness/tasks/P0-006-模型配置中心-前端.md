# 任务编号：P0-006

## 1. 任务目标

在 HR 管理端新增「模型配置」页面，对接 P0-005 创建的 Provider/Model 管理接口，支持可视化配置 LLM Provider 和 Model。

## 2. 对应缺陷

- **缺陷 1**：模型与 Provider 不可视化配置（前端侧）

## 3. 前置条件

- P0-005 完成（后端接口可用）

## 4. 允许修改的文件

- `hr-frontend/src/router/index.ts`（新增路由）
- `hr-frontend/src/App.vue`（新增菜单项，或在已有管理菜单下新增）
- `hr-frontend/src/views/hr/admin/`（新增 LlmConfigView.vue）
- `hr-frontend/src/api/`（新增 llm.ts）
- `hr-frontend/src/types/`（新增 llm.ts 类型）

## 5. 禁止修改的文件

- `logic-grpc-service/` 下所有文件
- `web-gin-service/` 下所有文件
- 已有业务页面和路由

## 6. 实现步骤

1. **路由与菜单**：
   - 新增路由 `/hr/admin/llm-config`，`meta.perm: PERM.SYSTEM_CONFIG_MANAGE`
   - 在侧边栏菜单「基础数据」分组或独立新增「模型配置」菜单项（图标 + 文字，使用 Element Plus Icons）

2. **类型定义** (`types/llm.ts`)：
   ```ts
   interface LlmProvider { id, name, base_url, provider_type, is_enabled, api_key_masked, extra_headers_masked, ... }
   interface LlmModel { id, provider_id, model_name, display_name, temperature, top_p, max_tokens, is_enabled, is_default, ... }
   ```

3. **API 层** (`api/llm.ts`)：
   - Provider CRUD + 连接测试
   - Model CRUD

4. **页面组件** (`LlmConfigView.vue`)：
   - 使用 Element Plus `el-tabs` 分为「Provider 管理」和「Model 管理」
   - Provider 列表：表格 + 新增/编辑弹窗
   - API Key 输入框使用 `type="password"` 且显示为 `show-password`
   - API Key 编辑时：空值表示不修改已有 Key
   - 连接测试按钮 + 结果反馈（成功/失败 + 错误信息）
   - Model 列表：按 Provider 分组，表格 + 新增/编辑弹窗
   - Model 参数编辑：temperature（滑块 0-2）、top_p、max_tokens
   - 默认模型标记

## 10. 权限与安全要求

- 页面需 `SYSTEM_CONFIG_MANAGE` 权限
- API Key 输入框 `type="password"`，禁止自动填充
- API Key 显示为脱敏格式
- 不在前端 localStorage 存储完整 API Key
