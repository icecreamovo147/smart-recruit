# 任务编号：P1-013

## 1. 任务目标

在 HR 管理端新增「数据源管理」页面，对接 P1-012 的数据源管理接口，支持可视化配置数据源连接、查看表结构、编辑字段语义和招聘指标口径。

## 2. 对应缺陷

- **缺陷 8**：无数据源管理 / 字段语义 / 口径配置（前端侧）

## 3. 前置条件

- P1-012 完成（后端接口可用）

## 4. 允许修改的文件

- `hr-frontend/src/router/index.ts`
- `hr-frontend/src/App.vue`
- `hr-frontend/src/views/hr/admin/`（新增 DataSourceView.vue）
- `hr-frontend/src/api/`（新增 datasource.ts）
- `hr-frontend/src/types/`（新增 datasource.ts 类型）

## 5. 禁止修改的文件

- `logic-grpc-service/` 下所有文件
- `web-gin-service/` 下所有文件
- 已有业务页面

## 6. 实现步骤

### 6.1 路由与菜单

- 新增路由 `/hr/admin/data-sources`，`meta.perm: PERM.SYSTEM_CONFIG_MANAGE`
- 在侧边栏菜单新增「数据源管理」菜单项

### 6.2 页面设计

1. **数据源管理（主视图）**：
   - `el-table`：名称/数据库类型/地址/库名/状态/操作
   - 新增/编辑弹窗：名称、数据库类型、主机、端口、库名、DSN 输入（密码框）
   - 连接测试按钮
   - 查看表结构入口

2. **表结构查看（子视图）**：
   - 左侧表列表（可搜索）
   - 右侧列详情（列名、类型、允许空、键类型）
   - 字段语义编辑：点击某字段可编辑其中文名、业务含义、分类、是否敏感

3. **指标口径（子视图）**：
   - `el-table`：指标名称/中文名/关联表/关联字段/操作
   - 新增/编辑弹窗：指标基本信息、关联表和字段多选
