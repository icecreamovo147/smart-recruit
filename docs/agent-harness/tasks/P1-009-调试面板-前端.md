# 任务编号：P1-009

## 1. 任务目标

在 HR 管理端新增「调试面板」页面，对接 P1-008 的调试接口，支持在线对话调试、查看原始 messages、模型请求参数、响应、工具调用 Trace、耗时和 Token。

## 2. 对应缺陷

- **缺陷 7**：无独立 Token / 成本统计与调试面板（调试面板前端）

## 3. 前置条件

- P1-008 完成（调试接口可用）
- P0-006 完成（模型选择器可用）
- P1-005 完成（Agent 选择器可用）

## 4. 允许修改的文件

- `hr-frontend/src/router/index.ts`
- `hr-frontend/src/App.vue`
- `hr-frontend/src/views/hr/admin/`（新增 PlaygroundView.vue）
- `hr-frontend/src/api/`（新增 debug.ts 或追加到 ai.ts）

## 5. 禁止修改的文件

- `logic-grpc-service/` 下所有文件
- `web-gin-service/` 下所有文件
- `AIChatView.vue`
- 其他已有业务页面

## 6. 实现步骤

### 6.1 路由与菜单

- 新增路由 `/hr/admin/playground`，`meta.perm: PERM.SYSTEM_CONFIG_MANAGE`
- 在侧边栏菜单新增「调试面板」菜单项

### 6.2 页面设计（左右分栏布局）

1. **左侧配置区**：
   - 模型选择下拉框
   - Agent 配置选择下拉框
   - Temperature/TopP/MaxTokens 参数调节（覆盖默认值）
   - 系统 Prompt 预览（只读）
   - 工具列表展示（该 Agent 绑定的工具）

2. **中间对话区**：
   - 消息列表（用户消息 + AI 回复）
   - 输入框 + 发送按钮

3. **右侧调试面板**：
   - Tabs 切换：「请求」「响应」「工具调用」「统计」
   - 「请求」Tab：展示原始 messages JSON + 模型参数
   - 「响应」Tab：展示流式响应原文
   - 「工具调用」Tab：时间线展示工具名/入参/结果/耗时（类似 P0-004）
   - 「统计」Tab：Token 估算、总耗时、工具统计
