# 任务编号：P1-012

## 1. 任务目标

新增数据源管理后端能力：支持配置数据库连接（目前为 MySQL）、读取表结构和字段信息、配置字段语义描述（中文说明）和招聘指标口径。

## 2. 对应缺陷

- **缺陷 8**：无数据源管理 / 字段语义 / 招聘指标口径配置（后端侧）

## 3. 前置条件

- M4 阶段（建议 P1-006/P1-007 完成后开始）

## 4. 允许修改的文件

- `logic-grpc-service/proto/recruitment.proto`
- `logic-grpc-service/recruitment/pb/`
- `logic-grpc-service/model/model.go`
- `logic-grpc-service/repository/`（新增 datasource_repo.go）
- `logic-grpc-service/service/`（新增 datasource_service.go）
- `logic-grpc-service/migrations/`（新增 migration）
- `web-gin-service/proto/recruitment.proto`（同步）
- `web-gin-service/recruitment/pb/`（同步）
- `web-gin-service/router/router.go`

## 5. 禁止修改的文件

- `ai/` 下所有文件
- 已有数据库连接初始化逻辑（不改动已有 MySQL 连接，数据源管理为新连接能力）
- 已有业务服务

## 6. 实现步骤

### 6.1 数据库

新增表 `data_sources`：
- `id`、`name`、`description`、`db_type`（mysql/postgres）、`dsn_encrypted`（AES-256-GCM 加密）、`host`、`port`、`database_name`
- `is_enabled`、`is_default`（默认数据源为已有业务库）
- `created_at`、`updated_at`

新增表 `field_semantics`：
- `id`、`data_source_id`、`table_name`、`column_name`、`column_type`
- `display_name`（中文名）、`description`（字段业务含义）
- `category`（分类：基础信息/招聘指标/候选人信息/岗位信息等）
- `is_sensitive`（是否敏感字段，如手机号/身份证）
- `created_at`、`updated_at`

新增表 `metric_definitions`：
- `id`、`name`、`display_name`、`description`、`calculation_sql`（可选）
- `related_table`、`related_fields`（JSON 字段名列表）
- `created_at`、`updated_at`

### 6.2 后端

1. 新增 proto rpc：
   - `ListDataSources` / `CreateDataSource` / `UpdateDataSource` / `DeleteDataSource` / `TestDataSourceConnection`
   - `ListTables`（列出某数据源的表）
   - `ListTableColumns`（列出某表的列）
   - `ListFieldSemantics` / `CreateFieldSemantic` / `UpdateFieldSemantic` / `DeleteFieldSemantic`
   - `ListMetricDefinitions` / `CreateMetricDefinition` / `UpdateMetricDefinition` / `DeleteMetricDefinition`
2. `TestDataSourceConnection`：用 DSN 尝试连接，超时 10s
3. `ListTables`：执行 `SHOW TABLES`
4. `ListTableColumns`：执行 `DESCRIBE table_name` 或查询 `information_schema`
5. DSN 加密存储（复用 P0-005 的加密方案）
