# Homepage surface brief

- Mode: Persuade.
- Audience: talent teams evaluating operational trust and developers evaluating open architecture.
- Job: understand the platform, see how its hiring, AI governance, and architecture connect, then inspect the repository.
- Primary action: view the GitHub repository. Secondary action: inspect architecture.
- Direction: Deployable Hiring System, using a Miura sheet that unfolds one connected platform from a compact starting point.
- Approved composition: a single-pull panorama, implemented in `src/assets/miura-deploy-hero.webp`.
- Memorable moment: the hero sheet opens across the right side and exposes recruiting workflow, governed AI evidence, and open architecture as one linked structure.
- Constraints: preserve bilingual content, dual themes, navigation anchors, localStorage behavior, copy action, accessibility, factual claims, existing logo, and URLs.

## Implementation inventory

| Ingredient | Commitment | Medium |
|---|---|---|
| Hero fold | One dominant horizontal Miura sheet covering roughly half the first viewport | Generated raster illustration, no embedded UI copy |
| Headline | Compact left block, obvious two-level hierarchy | Semantic HTML with a condensed engineered sans |
| Primary action | Gold fold-tab shape with clear contrast and tactile state | Semantic link plus CSS clip-path |
| Crease system | Fine diagonal rules that guide page rhythm | CSS and authored SVG geometry |
| Hiring / AI / architecture proof | Factual, labeled demonstrations without invented metrics | Semantic HTML and precise inline SVG diagrams |
| Paper and foil | Matte stock plus restrained material accent | Raster asset plus CSS color surfaces |
| Motion | The sheet deploys once on hero entry; section reveals stay quiet | CSS transforms and IntersectionObserver, disabled for reduced motion |
| Mobile | Fold becomes a wide visual below copy; diagrams stack and remain legible | Explicit single-column responsive CSS |
